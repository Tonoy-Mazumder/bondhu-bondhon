# BondhuBondhon

A community-driven event platform that connects people through social activities, volunteering, and community development initiatives.

## 🌐 Live Website

[Visit BondhuBondhon](https://bondhu-bondhon.vercel.app)

## ✨ Key Features

- **User Authentication:** Secure sign-up and sign-in with email and Google authentication using Better Auth.
- **Create Events:** Authenticated users can create community events with details, images, dates, locations, and participant capacity.
- **Manage Events:** Organizers can view, update, and delete their own events.
- **Upcoming Events:** Explore upcoming community events and view detailed event information.
- **Join Events:** Authenticated users can join available events and reserve their spots.
- **Cancel Participation:** Users can cancel their participation in events they have joined.
- **Joined Events:** View and manage all events that the logged-in user has joined.
- **Event Categories:** Browse events by categories such as Environment, Education, Health, Donation, and Community Service.
- **Responsive Design:** Enjoy a user-friendly experience across mobile, tablet, and desktop devices.
- **Dark Mode:** Switch between light and dark themes.

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the required environment variables.
4. Start the development server using `npm run dev`.

## 🎯 Project Goal

The goal of BondhuBondhon is to encourage social participation, build stronger communities, and make it easier for people to discover and participate in meaningful events.
